Questions

Frequently asked questions

Why are browser voices different on different devices?

The website reads the voices exposed by the Web Speech API. Chrome, Edge, Windows, macOS and installed language packs can expose different voice sets.

Why is the download voice separate from the playback voice?

Browser speech synthesis normally plays audio but does not expose the raw audio stream needed to save a real MP3. Downloadable audio therefore uses a separate TTS endpoint that returns MP3 bytes.

Does the site upload my TXT or Markdown file?

No. The file is read in your browser and placed into the editor. If you generate an MP3, the selected text is then sent to the configured TTS provider for synthesis.

Can I host this on GitHub Pages?

Yes. The project is static HTML, CSS and JavaScript, so it can be uploaded directly to a GitHub repository and published with GitHub Pages.
