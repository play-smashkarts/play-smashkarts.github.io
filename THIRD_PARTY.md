# Third-party service

VoiceCraft's downloadable MP3 mode currently calls the external SpeechSter TTS API hosted at `https://ahm7xmakki.com`.

Before public/production deployment, review the provider's current API documentation, privacy policy, terms, fair-use limits, uptime expectations and CORS support. These can change independently of this static project.

Browser/system playback uses the Web Speech API and does not depend on the MP3 endpoint.
