How VoiceCraft handles text

Browser Listen mode uses the Web Speech API and does not call VoiceCraft's natural MP3 endpoint. Natural MP3 mode sends the text you choose, selected voice index, pitch, and rate to the configured third-party TTS service at ahm7xmakki.com so it can return MP3 audio. Voice list data may be cached in your browser for performance. VoiceCraft itself does not include a server in this GitHub Pages build.

Do not enter sensitive or confidential text into MP3 mode unless you are comfortable sending it to that provider.
