Privacy

Privacy policy

Browser playback

VoiceCraft uses the browser Web Speech API for live playback. The website itself does not upload your text for this local/browser playback mode. Some browser-reported voices can be provided by the operating system or a browser/cloud provider, so their processing behavior is controlled by that provider.

MP3 generation

Downloadable MP3 audio is generated using the external SpeechSter API hosted at ahm7xmakki.com. When you choose to generate an MP3, the text in the editor, selected voice identifier, speed and pitch settings are sent to that provider so it can return audio/mpeg data. VoiceCraft asks for consent before the first MP3 request.

Local storage

Theme, voice choices, speed, pitch, volume and optional consent preference can be stored in your browser using localStorage. The website does not require an account.

Imported files

TXT and Markdown files are read locally in the browser. The source file is not uploaded as a file. Its text is only sent externally if you explicitly generate an MP3.

Hosting

If you publish this project on GitHub Pages or another host, that hosting provider may maintain standard server/CDN logs according to its own privacy policy.

Third-party terms

The external TTS provider is a separate service. Review its current privacy policy and terms before production use, and update this page if you change providers.
